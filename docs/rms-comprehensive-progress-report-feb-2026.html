1. Bonus Recognition Module

What Was Built

  • Database: bonus_recognition table with 6 recognition types
  • Controllers: Admin + Faculty + API controllers
  • Views: Submission form + admin review pages
  • Workflow: Integrated with approval system

Submission Form Fields

  • Recognition Type: Dropdown (6 options: Editorial Board, External Examiner, Regulatory Body, Workshop/Seminar, Keynote/Plenary, Journal Reviewer)
  • Title: Text field for recognition title
  • Organization: Organization or institution name
  • Journal/Conference Name: Related publication venue
  • Event Name: Name of event or activity
  • Event Date: Date picker for activity date
  • Description: Textarea for detailed description
  • Year: Academic year dropdown
  • Evidence Files: Multiple file upload (certificates, appointment letters, etc.)

What Was Built

RTN-3 Form Fields (Student Co-Authors)

RTN-4 Form Fields (Course File Updates)

  • Assessment Redesign: Changes to assessment methods
  • Case Study Documentation: New case studies added

4. Multiple Evidence Files Support

What Was Built

  • Polymorphic EvidenceFile model
  • Supports publications, grants, RTN, bonus
  • File categories: acceptance_letter, award_letter, certificate, etc.
  • Admin verification system
  • UUID-based secure file storage

Evidence Upload Features

  • Multiple File Upload: Support for unlimited files per submission
  • File Categories:
    • Acceptance Letter
    • Award Letter
    • Certificate
    • Appointment Letter
    • DOI Link/Proof
    • Meeting Agenda
    • Other Documents
  • File Types Accepted: PDF, DOC, DOCX, JPG, PNG (max 10MB per file)
  • Admin Verification: Mark files as verified after review
  • Preview & Download: View uploaded files inline or download

5. Workflow System

What Was Built

  • Unified workflow for all submission types
  • 3-tier approval: Faculty → Coordinator → Dean
  • Fallback routing when coordinator not assigned
  • Approve/reject/return actions
  • Complete audit trail via ApprovalHistory

Workflow States

draft → submitted → pending_coordinator → pending_dean → approved

Alternative paths: rejected, returned (for revision)

Workflow Management Features

  • Coordinator Assignment: Assign coordinators by college/department
  • Dean Assignment: Assign deans by college
  • Action Buttons: Approve, Reject, Return for Revision
  • Comments Field: Add notes with each action
  • History Timeline: Visual timeline of all approval actions
  • Status Tracking: Real-time status updates for submitters
  • Email Notifications: Automatic alerts at each workflow stage
  • Bulk Actions: Process multiple submissions at once
