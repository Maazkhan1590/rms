Questions for Discussion - MOU Module

Q1: Who can submit MOU entries?

Faculty only, Admin only, or Both?

Q2: Do MOUs need approval?

Auto-approved or require approval? If approval needed, who approves (Coordinator, Dean, Admin)?

Q3: Should MOUs contribute to faculty scoring?

If yes, what points per MOU type? Any maximum limits?

Q4: What evidence files are required?

Signed documents, agreements, proposals, or others?

Q5: How should MOU status be managed?

Auto-expire based on date, manual update, or send expiry notifications?

Q6: How to assign lead staff?

Can faculty assign themselves? Can multiple faculty be assigned? Need co-lead option?

Q7: How to track MOU outputs?

Link to actual publications/grants in system, free text, or both?

Q8: How to handle SDG selection?

Select from list? Mandatory or optional? Can select multiple SDGs?

Questions for Discussion - Adjunct Professor Module

Q1: Adjunct Professor Access & Management

Who should manage adjunct professor records?

  • Admin only (centralized management)?
  • Faculty members (self-registration or assignment)?
  • Both (admin creates, faculty can view/update their assigned adjuncts)?
Q2: Adjunct Professor-Faculty Association

How should adjunct professors be linked to faculty members?

  • One-to-one relationship (one adjunct per faculty)?
  • Many-to-many (multiple faculty can collaborate with same adjunct)?
  • Should there be a way to track collaborations/partnerships?
Q3: How to handle Google Scholar/Scopus data?

Manual entry only, or auto-fetch? How often to update? Who updates?

Q4: Should adjunct collaborations count in scoring?

If yes, same points or different? How to calculate co-authored publications?

Q5: What reports are needed?

List of adjuncts, profile pages, collaboration reports, or publication impact reports?

Q6: How to track appointments?

Need end date? Track renewals? Send renewal notifications?

Q7: Do adjunct records need approval?

If yes, who approves? Need to verify Google Scholar/Scopus profiles?

Q8: How to link adjuncts to publications?

Add field in publications? Support multiple adjuncts per publication? Can faculty tag when submitting?

Questions for Discussion - TRN Course Details & Types

Q1: What course information is needed?

Course code, name, semester, year? Separate module or part of RTN-4?

Q2: Who assigns RTN types to courses?

Faculty when submitting RTN-4, Admin/Coordinator, or pre-assigned in course catalog?

Q3: Are there more RTN types?

Currently RTN-3 and RTN-4. Need RTN-1, RTN-2, RTN-5, etc.? What are the criteria?

Q4: How to manage course files?

Store in system? Which file types (PDF, Word)? Version control? Who can access?

Q5: How to link RTN to courses?

Need course catalog? Link to specific courses? One RTN for multiple courses? Track course RTN history?

Q6: What evidence is required?

Updated syllabus, lecture materials, assessment redesign, case studies, student feedback?

Q7: How to score RTN courses?

Points per course? Maximum per semester/year? Different points per RTN type? How for multiple courses?

Q8: What reports are needed?

Courses with RTN, activity by course/faculty/semester, RTN type distribution, impact reports?

Q9: What approval workflow?

Same as RTN-3/RTN-4? Need course coordinators as approvers? Different levels per RTN type?

Q10: How to import TRN course data from Excel?

What is the Excel structure? How should data map to system fields?
