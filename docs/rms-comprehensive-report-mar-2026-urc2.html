3. Reporting System Working (How Reports Operate)

3.1 Report Data Flow

Stage What Happens Output
Data Collection Module records are captured from publications, grants, RTN, income, students, editorial, adjunct, and related entities. Structured source records with user ownership and timestamps.
Validation Inputs are checked for mandatory fields, type validity, and required evidence attachment consistency. Reliable data prepared for summaries and KPI calculations.
Aggregation Reporting logic groups data by faculty, period, category, and KPI dimensions (target, achieved, ratio, amount). Computed metrics for institutional and committee reports.
Presentation Data is rendered in summary cards and detailed tables for project tracking, committee review, and AB reporting. Human-readable dashboard views and printable report pages.
Export / Review Reports are prepared for print/PDF and management review workflows with clear status labels and comments. Governance-ready outputs for URC and AB meetings.

3.2 Report Types Supported / Targeted

  • Module completion and enhancement status reports.
  • KPI achievement reports (target versus achieved).
  • Quarterly research progress monitoring reports.
  • Annual faculty research plan achievement reports.
  • Faculty profile and enriched CV information reports.
